# Пример: демата и решенията за примерния интензив

Всеки раздел носи JSON блок; `organizer.py fill` ги влива в event.json дословно по `sources`.

## 1. Стъпките на демата: topics[n].demo.steps (добавят се след описанието)

```json
{"demo_steps": {
  "1": ["Пробата: една задача, зададена два пъти — отговорите са един до друг на екрана."],
  "2": ["Пробата: отговорът цитира реда от документа, а на въпрос извън него казва „не знам“."]
}}
```

## 2. Раздел на началната страница: home.sections

```json
{"title": "Демата — готови и изпитани",
 "intro": "Пуснахме по едно демо за всяка тема на машината на лабораторията.",
 "items": [
  {"title": "1 · Първи разговор", "text": "Една задача, два начина. [Виж демото](tema-01-parvi-razgovor.html)"},
  {"title": "2 · Памет", "text": "Отговор с цитат. [Виж демото](tema-02-pamet.html)"}
 ]}
```
