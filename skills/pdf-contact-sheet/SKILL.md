# pdf-contact-sheet — целият PDF на една картинка

## Какво иска
- `ВХОД.pdf` и `ИЗХОД.png` (или `.jpg`)
- `--cols N` — колони (по подразбиране — мрежа, близка до 16:9)
- `--thumb 240` — ширина на една страница в пиксели
- `--max-pages 400` — горна граница за много дълги файлове
- `--force` — позволи презаписване на съществуващ изход

## Какво връща
Нова картинка: страниците подред, над всяка — `номер / общо`, на тъмен фон. На екрана — един ред:
`файл.pdf: 11 страници → изход.png (1260x1123, 5×3)`.

Код на изход: 0 — готово · 2 — грешни аргументи (или изходът вече съществува) · 3 — липсва pymupdf или Pillow
(съобщението казва точно какво да се инсталира).

## Ниво
чернови — входният PDF само се чете; пише се един нов файл-картинка и не се презаписва нищо без `--force`.

## Къде тече
Локално, без мрежа. Незадължителни зависимости: `python3 -m pip install pymupdf pillow`.

## Пример
```bash
bin/shinkansen run pdf-contact-sheet scan-2026-09.pdf /tmp/scan-sheet.png --thumb 200
# scan-2026-09.pdf: 24 страници → /tmp/scan-sheet.png (1480x1466, 7×4)
```
